# Subhadeep Mandal — Dev.SUBHO Portfolio

Static HTML/CSS/JavaScript portfolio prepared for GitHub + Cloudflare Pages.

## Main files
- `index.html` — portfolio UI and behavior
- `blogs.json` — blog posts; add posts here without changing the blog rendering code
- `data/site.json` — identity/contact reference
- `data/projects.json` — project reference data
- `data/skills.json` — skill reference data
- `assets/images/` — profile/project images
- `assets/resume/Subhadeep_Mandal_Resume.pdf` — your real resume
- `robots.txt` and `sitemap.xml` — search-engine discovery

## Deploy
Push the folder to GitHub, then connect the repository to Cloudflare Workers & Pages.

## Important
Search for `YOUR-` before deployment. Replace every placeholder with a real value or remove the corresponding item.
